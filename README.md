# Materials for the course MS-C1300 Complex Analysis 2024

 * [a theory blueprint](https://kkytola.github.io/Complex-analysis-course/)
 * weekly exercise sheets

The theory blueprint is a [Verso Blueprint](https://github.com/leanprover/verso-blueprint) project written in
Lean/Verso markup; see [`AUTHORING.md`](AUTHORING.md) for how to build and edit it. The web site (course home
page, blueprint, dependency graph, PDF) is built and deployed by GitHub Actions
(`.github/workflows/blueprint.yml`).
